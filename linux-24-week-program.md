# Подробная программа обучения Linux на 24 недели

Цель: системное освоение Linux от базовой навигации до администрирования, автоматизации и практического проекта.

---

## Неделя 1. Linux: навигация и работа с файлами
Изучить: `pwd`, `ls`, `cd`, `mkdir`, `touch`, `cp`, `mv`, `rm`; `cat`, `less`, `head`, `tail`; права `chmod`, `chown`, `sudo`.

Практика:
- Создать учебную структуру каталогов с вложенными папками и файлами.
- Использовать `ls` с разными опциями, чтобы показать права, размер и дату.
- Найти и удалить файлы по условию (`find`, шаблоны `*.log`, старше N дней).
- Изменить права на файл и объяснить результат: кто может читать, писать, выполнять.
- Создать файл и просмотреть его содержимое разными командами.

Критерий готовности: задания выполнены без копирования готового решения, код загружен в Git, ошибки и выводы записаны в README.

---

## Неделя 2. Работа с текстом и поиск данных
Изучить: `grep`, `find`, `sed`, `awk`, `sort`, `uniq`, `wc`, `cut`, `tr`.

Практика:
- Найти строки по шаблону в нескольких файлах и собрать результаты.
- Отсортировать данные, удалить дубликаты и подсчитать строки.
- Извлечь поля из логов или CSV.
- Создать простой фильтр через `grep | sort | uniq | wc`.

Критерий готовности: выполнены практические задания, результаты задокументированы, изменения закоммичены.

Практика:

- Использовать пайпы для передачи вывода одной команды другой.

Критерий готовности: решения работают стабильно, есть пояснения в README.
