# TokenFlow overview

TokenFlow is a context optimization layer for LLM-powered tools, agents, and workflows.

It helps teams reduce prompt size while preserving critical instructions, user intent, and relevant facts.

## Core capabilities

- Deduplication
- History summarization
- Relevance scoring
- Budget-aware pruning
- Model routing
- Metrics collection

## Typical use cases

- Knowledge work agents
- Chat assistants with long history
- RAG and document-grounded workflows
- Compliance-sensitive prompts
- Token cost reduction in production systems
